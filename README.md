Project Name: ReZero (Recycle to Zero Waste)
Vision: Transform Rwanda’s waste management into a profitable, tech-driven circular economy.
Target: 3.4 million Rwandan households, leveraging 90% smartphone penetration.
Tech Stack:
Frontend: Flutter & Dart (cross-platform, responsive, animated UI).
Backend: Supabase (PostgreSQL, PostGIS, Realtime, Auth, Row-Level Security).
State Management: Riverpod.
Localization: English, French, and Kinyarwanda.
Core Innovative Features:
AI Waste Classifier: Snap a photo to auto-categorize waste and estimate volume.
Smart Logistics: PostGIS-powered route optimization for collectors to minimize fuel.
Dynamic Pricing: Real-time market value estimation for transparent, fair payouts.
Gamification: "Eco-Murakoze" points, digital badges, and Umudugudu leaderboards.
Digital Wallets: Seamless MTN MoMo and Airtel Money integration for instant tips.
Community Hubs: Aggregated pickup points for rural/peri-urban collection efficiency.
